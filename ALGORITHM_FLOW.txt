【 상세 프로세스 플로우 (프레임 단위) 】

입력: RGB (및 선택적 Depth)
  1) `ObjectDetectionCore.detect(rgb)` → `detections` 리스트
     - 각 detection: bbox [x1,y1,x2,y2], confidence, class_id, class_name

  2) 깊이 추출 (가능할 때)
     - `example_usage._estimate_depth_from_bbox(depth_frame, bbox)`
       - ROI내 유효 깊이값(>0) 선택
       - IQR로 이상치 제거: Q1,Q3,IQR 계산 후 중앙값 사용
       - 결과가 없으면 이전 depth 또는 추정값 사용

  3) 추적 및 상태 갱신
     - `KalmanTracker.update(detection_measurement)`
       - 예측(prediction) → 측정치로 업데이트 → 상태(위치, 속도) 반환
     - 속도 계산은 칼만 상태를 우선 사용 (권장)

  4) 미래 위치 예측
     - `KalmanTracker.predict_future(frames=16)` → future_positions

  5) 위험도 평가
     - `CollisionRiskAssessment.assess_risk(filtered_state, ego_state)`
       - current_distance = ||obj_pos - ego_pos||
       - relative_velocity = dot(obj_vel - ego_vel, direction)
       - closing_speed = -relative_velocity (양수면 접근)
       - TTC = (current_distance - safety_distance) / closing_speed
       - collision_probability = sum(weighted indicators) (clamped to 1.0)
       - risk_score, risk_level 도출 (SAFE/CAUTION/DANGER)

  6) 시각화 및 저장
     - 2D 프레임에 3D box, 텍스트, 위험 바 표시
     - BEV 렌더러에 객체 점표시(색상: RED/ORANGE/GREEN), 거리 표시
     - 파일 저장 옵션:
         - 메인 출력 MP4 (기본)
         - BEV 전용 MP4 (추가 파일) — `example_usage.run(output_bev_file=...)`

【 상세 프로세스 플로우 】

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[1단계] 객체 감지 (ObjectDetectionCore.detect())
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

입력:
  - RGB 프레임 (640x480 또는 가변 해상도)
  - enable_tracking: True (YOLO 내부 추적 활성화)

처리:
  1) YOLOv11n 모델로 객체 감지
     ├─ 모델 크기: nano, small, medium, large, extra
     ├─ 신뢰도 임계값: 0.25 (기본값)
     └─ IoU 임계값: 0.45 (기본값)
  
  2) YOLO 내부 추적 (enable_tracking=True)
     └─ 프레임 간 객체 ID 유지
  
  3) 각 감지 객체에 대해:
     ├─ 바운딩박스 추출: [x1, y1, x2, y2]
     ├─ 신뢰도 점수 (0~1)
     ├─ 클래스 ID 및 클래스명
     ├─ 객체 ID (추적 ID)
     └─ 궤적 저장 (최대 20개 프레임)

출력:
  - annotated_image: 바운딩박스가 그려진 이미지
  - detections: [{
      'bbox': [x1, y1, x2, y2],
      'confidence': float,
      'class_id': int,
      'object_id': int,
      'class_name': str
    }, ...]

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[2단계] 칼만 필터 추적 (KalmanTracker.update())
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

목적: 노이즈 제거, 속도 추정, 궤적 부드럽게 함

상태 벡터 (11차원):
  ┌──────────────────────────────────────┐
  │ x, y, z          → 3D 위치 (미터)   │
  │ width, h, length → 3D 크기           │
  │ yaw              → 회전 각도         │
  │ vx, vy, vz       → 3D 속도           │
  │ v_yaw            → 각속도             │
  └──────────────────────────────────────┘

칼만 필터 사이클:

  1) 예측 단계 (Prediction)
     └─ 이전 상태와 속도 기반으로 현재 상태 예측
        state_predicted = F × state_previous + velocity × dt
  
  2) 측정값 준비
     ├─ 깊이값 추출 (RealSense 또는 바운딩박스 크기로 추정)
     │  └─ RealSense: 깊이 프레임에서 ROI(±20px) 중앙값 추출
     │  └─ 웹캠: 바운딩박스 크기로부터 거리 추정
     ├─ 위치: (x_norm, y_norm, depth)로 정규화
     │  └─ x_norm = (center_x - width/2) / width  [-0.5, 0.5]
     │  └─ y_norm = (center_y - height/2) / height [-0.5, 0.5]
     └─ 크기 및 방향: 바운딩박스에서 추출
  
  3) 업데이트 단계 (Update)
     └─ measurement와 prediction의 가중 평균으로 상태 갱신
        state_updated = weighted_average(predicted, measured)
  
  4) 속도 추정
     └─ velocity = (location_current - location_previous) / dt
  
  5) 이력 저장
     └─ 최대 5 프레임 이력 유지

출력:
  filtered_state: {
    'location': [x, y, z],
    'velocity': [vx, vy, vz],
    'dimensions': [h, w, l],
    'orientation': yaw,
    'angular_velocity': v_yaw,
    ...추가 측정값들
  }

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[3단계] 미래 위치 예측 (KalmanTracker.predict_future())
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

목적: 다음 1~2초 동안 객체의 예상 위치 계산

방법: 등속 운동 모델 (Constant Velocity Model)

  future_position(t) = current_position + velocity × t

처리:
  1) 예측 프레임 수: 16 (30fps 기준 ~0.5초)
  2) 각 프레임별로 등속도로 진행하는 위치 계산
     
     Frame 0 (현재):   pos = [x0, y0, z0]
     Frame 1:          pos = [x0 + vx/30, y0 + vy/30, z0 + vz/30]
     Frame 2:          pos = [x0 + 2×vx/30, y0 + 2×vy/30, z0 + 2×vz/30]
     ...
     Frame 16:         pos = [x0 + 16×vx/30, y0 + 16×vy/30, z0 + 16×vz/30]

출력:
  future_positions: [
    [x1, y1, z1],  # 1프레임 후
    [x2, y2, z2],  # 2프레임 후
    ...
    [x16, y16, z16] # 16프레임 후
  ]

[4단계] 충돌 위험도 평가 (CollisionRiskAssessment.assess_risk())
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【 4-1. 현재 상태 분석 】

  1) 현재 거리 계산
     current_distance = ||obj_position - ego_position||
     └─ 3D 유클리드 거리 (미터)
  
  2) 현재 속도
     current_velocity = ||obj_velocity||
  
  3) 상대 속도 계산 (음수 = 가까워짐)
     ├─ 상대 위치 벡터: rel_pos = obj_pos - ego_pos
     ├─ 정규화: direction = rel_pos / ||rel_pos||
     ├─ 상대 속도 벡터: rel_vel = obj_vel - ego_vel
     └─ 상대 속도: relative_speed = dot(rel_vel, direction)
        → 음수면 자차에 접근 중

【 4-2. Time-to-Collision (TTC) 계산 】

  공식:
    closing_speed = -dot(relative_velocity, direction)
    safety_distance = (||obj_size|| + ||ego_size||) / 4
    
    TTC = (current_distance - safety_distance) / closing_speed
  
  조건:
    ├─ closing_speed ≤ 0 → TTC = None (접근하지 않음)
    ├─ TTC < 0 → TTC = 0.0 (이미 충돌 범위)
    └─ TTC > 0 → 예상 충돌 시간(초)
  
  위험도 판정:
    ├─ TTC < 2.0초 → DANGER (위험)
    ├─ TTC < 3.5초 → CAUTION (주의)
    └─ TTC ≥ 3.5초 → SAFE (안전)

【 4-3. 충돌 확률 계산 (0.0 ~ 1.0) 】

  여러 요소의 가중 합:
  
  prob = 0.0
  
  1) TTC 기반 (최대 0.6)
     ├─ TTC < 2.0초 → +0.6
     ├─ TTC < 3.5초 → +0.3
     └─ 그 외 → +0.0
  
  2) 거리 기반 (최대 0.2)
     └─ distance < 2.0m (안전거리) → +0.2
  
  3) 접근 속도 기반 (최대 0.2)
     └─ relative_velocity < -0.3 m/s (빠르게 가까워짐) → +0.2
  
  최종: collision_probability = min(prob, 1.0)

【 4-4. 위험도 등급 판정 (Risk Level & Score) 】

  위험도 점수 계산 (0 ~ 100):
  
  risk_score = 0
  
  1) TTC 점수 (최대 40)
     ├─ TTC < 2.0초 → +40
     ├─ TTC < 3.5초 → +20
     └─ 그 외 → +5
  
  2) 거리 점수 (최대 30)
     ├─ distance < 2.0m → +30
     ├─ distance < 3.0m → +15
     └─ 그 외 → +5
  
  3) 접근 속도 점수 (최대 20)
     ├─ relative_velocity < -0.5 m/s → +20
     ├─ relative_velocity < -0.3 m/s → +10
     └─ 그 외 → +0
  
  4) 충돌 확률 점수 (최대 10)
     └─ +collision_probability × 10
  
  등급 결정:
    ├─ risk_score ≥ 60 → 'DANGER' (위험)
    ├─ risk_score ≥ 30 → 'CAUTION' (주의)
    └─ risk_score < 30 → 'SAFE' (안전)

【 4-5. 충돌 영향도 계산 (물리 기반) 】

  클래스별 예상 질량:
    person: 70kg, bicycle: 15kg, motorcycle: 150kg
    car: 1500kg, truck/bus: 5000kg, 기타: 100kg
  
  충돌 에너지 (운동 에너지):
    E = 0.5 × m × v²
  
  상대 에너지 (정규화):
    reference_energy = 0.5 × 1500 × 5.0² = 18,750 J
    actual_energy = 0.5 × mass × object_velocity²
    impact = (actual_energy / reference_energy) × 100
  
  범위: 0 ~ 100

출력:
  RiskAssessment {
    object_id: int
    class_name: str
    
    현재 상태:
    ├─ current_position: [x, y, z]
    ├─ current_distance: float (미터)
    ├─ current_velocity: float (m/s)
    
    미래 예측:
    ├─ future_positions: [[x1,y1,z1], ..., [x16,y16,z16]]
    └─ predicted_distance: float (미터, 16프레임 후)
    
    위험도 분석:
    ├─ time_to_collision: float or None (초)
    ├─ relative_velocity: float (m/s, 음수=접근)
    ├─ approach_direction: [nx, ny, nz] (단위벡터)
    ├─ collision_probability: float (0.0~1.0)
    ├─ risk_level: 'safe'|'caution'|'danger'
    ├─ risk_score: float (0~100)

    └─ collision_impact: float (0~100)
  }

① YOLO tracking 제거 / Kalman으로 단일화
  현재: YOLO tracking + Kalman = 이중
  목표: Kalman 중심으로 통일
  
  변경:
    - YOLO: detection만 수행 (predict() 사용, track() 미사용)
    - 매칭: Hungarian Algorithm으로 자체 구현
    - 추적: Kalman만 담당
  
  장점:
    - 이중 계산 제거
    - ID 일관성 개선
    - 성능 ~5% 향상

② Velocity 계산 일원화
  현재: 외부 계산 + Kalman 내부 계산
  
  개선:
    filtered_velocity = kf.x[7:10]  # Kalman 상태만 사용
    # 외부 계산 제거
  
  또는:
    hybrid = 0.7 * kalman_velocity + 0.3 * observed_velocity
  
  추천: Kalman만 사용 (더 안정적)

③ Hungarian Algorithm 추가
  새 파일: association.py
  
  기능:
    - IOU 계산 (바운딩박스)
    - Cosine distance (특징)
    - 최적 매칭
  
  코드 예시:
    def match_detections(detections, tracked_objects):
      cost_matrix = compute_iou_matrix(...)
      matched_pairs = hungarian_algorithm(cost_matrix)
      return matched_pairs

    - TTC 정확도 향상
  
  예시:
    if vehicle.has_speed_input():
      ego_vel = vehicle.get_velocity()
      risk_assessor.set_ego_state(ego_pos, ego_vel)

    depth_frame, confidence_frame = realsense.get_depth_with_confidence()
    
    valid_mask = confidence_frame > 0.7
    filtered_depth = depth_frame * valid_mask
